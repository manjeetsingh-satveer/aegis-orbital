# ⚔️ AEGIS — Orbital Threat Intelligence Platform

Live satellite tracking with SGP4, paired with an Isolation Forest anomaly
detector trained on simulated orbital attack signatures — GPS spoofing, signal
jamming, command injection, replay, and ground-station phishing.

## What it does

**Tracks real satellites.** Pulls live TLE data from
[CelesTrak](https://celestrak.org) — the feed NASA, ESA, and the US Space Force
publish through — and propagates positions with **SGP4**, the orbital model NORAD
has used since the 1970s. Around 120 objects across Starlink, the ISS and
Tiangong, the GPS constellation, and NOAA/EUMETSAT weather satellites.

**Detects attack signatures.** Runs a real Isolation Forest over six telemetry
features and reports what the model actually concluded, including when it fails
to flag something.

> **The telemetry is simulated.** Satellite operators do not publish uplink SNR
> or telecommand rates, so there is no live feed to consume. The baselines and
> attack signatures are modelled on published incident reporting and are used to
> exercise the detector. The UI labels simulated data as such. Orbital positions
> *are* real.

## Detector performance

Generated by `npm run evaluate` and read from
[`lib/detection/evaluation-results.json`](lib/detection/evaluation-results.json).
CI fails if the committed numbers stop matching a real run.

| Metric | Value |
|---|---|
| Accuracy | 93.0% |
| Precision | 98.6% |
| Recall | 87.2% |
| F1 | 92.6% |
| False positive rate | 1.2% |
| ROC AUC | 0.995 |

Recall by attack class, at the shipped threshold:

| Attack | Recall |
|---|---|
| Signal jamming | 100% |
| Command injection | 100% |
| Replay | 100% |
| GPS spoofing | 99.6% |
| **Ground-station phishing** | **36.4%** |

That last row is the interesting one, and it is not a defect.

Phishing compromises a human operator, not the spacecraft. The radio link stays
healthy — SNR, signal strength, and packet loss all sit at nominal — and only the
command cadence shifts, well within the range of a busy but legitimate operator.
There is very little for a telemetry-based detector to find.

**This is why the Viasat attack worked.** Watching the space segment does not
catch an attacker who logged into the ground segment with valid credentials. The
detector reproduces that blind spot rather than hiding it, and the console shows
early phishing stages as *below threshold* while later stages — once the command
burst starts — are flagged.

Protocol: trained on nominal traffic only (Isolation Forest assumes a
predominantly-normal training set); the alerting threshold is fixed from the
training score distribution at 99% specificity, so it never sees the test set;
evaluated on 4,000 nominal and 4,000 attack samples drawn from a separate RNG
stream.

## Running it

```bash
npm install
npm run dev
```

No API keys. CelesTrak is fetched server-side; if it is unreachable the app falls
back to a bundled snapshot of real elements and says so in the UI.

| Command | Purpose |
|---|---|
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm run verify` | Typecheck, lint, unit tests |
| `npm run test:coverage` | Unit tests with enforced coverage thresholds |
| `npm run test:e2e` | Playwright suite against a production build |
| `npm run evaluate` | Regenerate detector metrics |
| `npm run refresh:fallback` | Refresh the bundled TLE snapshot from CelesTrak |

## Architecture

Next.js 16 (App Router) with TypeScript in strict mode. Full detail in
[ARCHITECTURE.md](ARCHITECTURE.md); the two decisions worth knowing up front:

**The globe is not rendered by React.** It runs ~120 satellites at 60fps. Driving
that through React state would mean roughly 10,000 updates per second, so the
canvas renderer is a plain TypeScript class with its own animation loop. React
mounts it once, pushes data in through setters, and receives only selection
events back. SGP4 runs at 10Hz with interpolation between exact solutions.

**Satellite data is fetched server-side.** That removes the CORS constraint,
which removes the need for third-party proxies, which removes the injection sink
that came with them — and lets the CSP be `default-src 'self'`. The upstream
fetch is cached for an hour, so CelesTrak sees one request per group per hour
regardless of traffic.

```
lib/orbital/     TLE parsing, SGP4, orbit classification, CelesTrak client
lib/detection/   Isolation Forest, telemetry model, metrics, evaluation harness
lib/renderer/    projection, label placement, canvas globe
lib/simulation/  reducer driving the threat sandbox
```

## Threat sandbox

Five simulations, each with a published real-world precedent:

| Attack | Severity | Precedent |
|---|---|---|
| GPS spoofing | Critical | Black Sea GPS anomalies (2017); Iranian capture of a US RQ-170 (2011) |
| Signal jamming | Warning | Recurrent GPS jamming over the Korean peninsula |
| Command injection | Critical | Viasat KA-SAT modem wiper deployment (February 2022) |
| Replay | Warning | Telecommand replay without packet authentication |
| Ground-station phishing | Critical | Viasat KA-SAT ground network intrusion (February 2022) |

### On the Viasat figures

Reporting on the February 2022 KA-SAT attack mixes two numbers that are often
conflated, so to be precise:

- **~5,800 Enercon wind turbines** in Germany lost remote monitoring. This is the
  most frequently cited figure, and it does **not** refer to modems.
- **Tens of thousands of modems** were disabled across Europe. Viasat's own
  incident statement describes "tens of thousands"; the ~45,000 figure that
  circulates refers to replacement units ordered, not a confirmed count of
  bricked devices.

Earlier versions of this README quoted 45,000 modems as fact while the
application itself said 5,800. Both figures are now stated with their actual
meaning.

## Prior art

AEGIS is not the first work on space cybersecurity, and it is worth being clear
about what came before:

- **[SPARTA](https://sparta.aerospace.org/)** (Aerospace Corporation, 2022) — the
  established ATT&CK-style matrix for space systems.
- **[NOS3](https://github.com/nasa/nos3)** (NASA) — an open-source satellite
  simulator used for security research.
- **Sat-ATT&CK** (IEEE AICCSA 2025) — a more recent academic threat framework.

What AEGIS contributes is a working, tested implementation that puts live orbital
tracking and a reproducible anomaly detector in one interface, with its
evaluation methodology published rather than asserted. It is a demonstration and
research tool, not an operational security control.

## Security

Server-side data fetching, sanitisation of untrusted upstream strings, Zod
validation at the boundary, rate-limited API routes, and a documented CSP —
including an honest account of why `script-src` permits inline scripts. See
[SECURITY.md](SECURITY.md).

Vulnerability reports go through
[GitHub Security Advisories](https://github.com/manjeetsingh-satveer/aegis-orbital/security/advisories/new).

## Accuracy of orbital positions

SGP4 is accurate to roughly 1 km at the TLE epoch and degrades by a few km per
day as elements age. The UI states expected error as a function of the age of the
loaded elements rather than quoting a fixed figure, and shows whether data came
from CelesTrak or the bundled snapshot.
